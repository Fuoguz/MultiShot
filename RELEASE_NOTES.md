# MultiShot v0.5.0

**Capture several screenshots. Paste them all at once.**  
**连续截图，一次粘贴。**

This is the first public GitHub release of MultiShot.

## Highlights

- Continuous screenshot sessions: capture multiple areas/windows, then paste the entire group with one `Ctrl+V`.
- Smart top-level window snapping plus free-region selection.
- Pixel magnifier for precise free selection.
- Undo the last capture and safely clean temporary files.
- Simplified Chinese / English UI with system-language detection.
- Fully customizable global hotkeys, persisted locally.
- Lightweight native Windows implementation: no Electron, Node.js, Python, cloud account, or telemetry.
- New MultiShot application icon used by the built EXE and tray UI.

## 已实现

- 连续截图后整组一次粘贴。
- 窗口自动吸附 + 手动自由框选。
- 像素放大镜、撤销、临时文件安全清理。
- 简体中文 / English 双语适配。
- 截图 / 撤销 / 完成三组全局快捷键可自定义并持久保存。
- 轻量原生 Windows 实现，不依赖 Electron、Node.js、Python 或云服务。
- 正式应用图标。

## Tested

The multi-image paste workflow has been tested successfully with ChatGPT Web, Feishu/Lark, WeChat, QQ, and Windows File Explorer folders.

> MultiShot is currently unsigned, so Windows SmartScreen may show a warning for downloaded binaries.
